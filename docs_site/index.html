Zero Bloat Architecture

Built for Performance & Simplicity

Everything needed for robust uptime monitoring without the heavyweight infrastructure footprint.

synthetic-probes

Synthetic HTTP Probes

High-frequency HTTP/HTTPS checks, customizable polling intervals, configurable expected status codes, retry thresholds, and payload timeouts.

status-pages

Multi-Status Pages & Slug Routing

Isolated status pages served on custom URL slugs (/status/:slug), customizable titles/descriptions, and categorized monitor groupings (e.g. “REST APIs”, “Web Applications”).

maintenance

Planned Maintenance Windows

Schedule maintenance windows with auto-suppression of webhook notifications, explicit “MAINTENANCE” status pills, and active announcement banners on public status pages.

percentiles

Latency Percentiles (P50 / P95 / P99)

Real-time response time analysis computing P50 median, P95, P99 tail latency, and 24-hour hourly performance averages from rolling SQLite telemetry logs.

webhooks

Stateful Webhook Alerting

Zero-spam notification system for Discord, Slack, and generic HTTP endpoints with automatic downtime resolution (RESOLVED) notifications and duration metrics.

rust / sqlite

Zero-Dependency Single Binary

Compiled Rust engine (axum + tokio + SQLite WAL), <15MB idle memory footprint, constant-time JWT authentication (subtle), and tower-governor IP rate limiting.

Self-Host KeepUp in 60 Seconds

Run KeepUp as a lightweight Docker container with persistent SQLite telemetry storage: 

docker run -d \
  --name keepup \
  -p 3000:3000 \
  -v keepup-data:/data \
  -e ADMIN_USER=admin \
  -e ADMIN_PASSWORD=supersecret \
  ridloghfry/keepup:latest
Once running, navigate to:
  • Dashboard: http://localhost:3000/
  • Public Status: http://localhost:3000/status
