Zero Bloat Architecture

Built for Performance & Simplicity

Everything needed for robust uptime monitoring without the heavyweight infrastructure footprint.

tokio / axum

Sub-15MB Memory Footprint

Engineered with async Rust. Idles at less than 15MB RAM and sub-1% CPU, ideal for cost-efficient VPS instances or edge hardware.

rust-embed

Single Standalone Binary

All HTML, CSS, JavaScript, icons, and database migrations are baked directly into the executable. No Node.js runtime or external cache required.

sqlite3-wal

Embedded SQLite with WAL

Self-contained persistence using SQLite configured with Write-Ahead Logging and synchronous normal mode for high-throughput, non-blocking telemetry logging.

webhooks

Stateful Spam-Free Alerts

Rich Discord embeds, Slack Block Kit messages, and generic webhooks fire only on state changes (DOWN/RESOLVED) with configurable retry thresholds.

status-page

Public Status Page & Themes

Built-in customer-facing status page featuring 7-day uptime pills, 24-hour latency breakdowns, component grouping, and clean responsive dark themes.

hardened

Single-Admin Hardened Security

Constant-time password comparison, signed 7-day HttpOnly JWT session cookies, and brute-force IP rate limiting powered by tower-governor.

Self-Host KeepUp in 60 Seconds

Run KeepUp as a lightweight Docker container with persistent SQLite telemetry storage: 

docker run -d \
  --name keepup \
  -p 3000:3000 \
  -v keepup-data:/data \
  -e ADMIN_USER=admin \
  -e ADMIN_PASSWORD=supersecret \
  ridloghfry/keepup:latest
Once running, navigate to:
  • Dashboard: http://localhost:3000/
  • Public Status: http://localhost:3000/status
